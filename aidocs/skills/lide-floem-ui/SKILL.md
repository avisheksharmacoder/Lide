# (DEPRECATED) Floem UI Architecture

> [!WARNING]
> The Floem UI architecture has been completely replaced by **Iced** (`crates/app-iced`) using The Elm Architecture (TEA).
> Please use the active skill **[`lide-iced-ui`](../lide-iced-ui/SKILL.md)** instead.

Lide no longer uses Floem or reactive signals (`RwSignal`). All presentation state, rendering, and async event streaming are now governed by `crates/app-iced` and documented in **[`lide-iced-ui`](../lide-iced-ui/SKILL.md)**.
